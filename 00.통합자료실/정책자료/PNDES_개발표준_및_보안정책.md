# PNDES 개발표준 및 보안정책

> 이 문서는 `PRD.md`의 "기술 스택", "비기능 요건", "부록 J. 비기능 요구사항 상세"를 기준으로 정리한 개발/보안 준수사항입니다.

## 1. 개요

현대모비스 생산기술포털(PNDES)은 자체 개발 표준·보안 정책이 확립된 전사 시스템이며, 본 프로젝트(신규 메뉴 2건)는 그 표준을 그대로 준수해야 한다. AP-Framework V0.43의 기본 기술 스택(Next.js/Vercel 등)은 적용하지 않으며, 아래 PNDES 표준이 최우선한다.

| 개발언어 | Java, JQuery, HTML5 | IntelliJ 사용 |
| 개발 프레임워크 | Java Spring | |

### 2.1 PNDES 공통 기능 필수 활용

신규 개발 시 아래 PNDES 공통 기능을 반드시 활용하고, 임의로 재구현하지 않는다.

- 메뉴관리, 권한관리, 공통코드관리, 다국어관리(한/영/중), 번역(H translate)
- 결재(자체 구현 공통 기능)
- 파일 업/다운로드 컴포넌트: INNORIX WP9
- 그리드: 커스텀 그리드 패턴
- 차트: Highcharts
- 웹에디터: daum Editor
- 문서 보안: SoftCamp Document Security, SoftCamp SecureWeb, AIP(MS)
- ETL: 데이터스트림즈 TeraStream

## 3. 보안 정책

### 3.1 취약점 대응

- OWASP(국제 웹 어플리케이션 보안기구) Top 10 취약점을 모두 고려하여 구축
- 국가정보원 국가사이버안전센터 보안관리 매뉴얼 명시 취약점 준수
- 개발 프로그램에 대한 보안 취약점 사전 점검 및 보완조치 (취약점 분석 가이드는 현대오토에버에서 제공)

### 3.2 권한/인증

- 권한/사용자관리는 PNDES 공통 기능을 활용하여 권한 체크 로직 적용
- 모의해킹 필수 점검 대상
- 로그인/로그아웃, 접속 메뉴, 다운로드 이력 등을 PNDES 사용자 로그 관리 기능에 연계

### 3.3 데이터 보호

- 개인정보는 암호화하여 저장
- 보안이 중요한 데이터 전송 시 SSL 인증서 적용
- 첨부파일: 허용 확장자 및 유해 파일 정책 적용, 조회·다운로드·메일공유 이력 관리, 외부 반출 통제

### 3.4 응답 성능

- 사용자 화면은 최대 3초 이내 응답 성능을 보장해야 함 (예외 적용 시 별도 제시)

## 4. 테스트/결함관리 정책

| 구분 | 정책 |
|---|---|
| 단위테스트 | 개발 진행 주 완료된 단위기능에 대해 병행 수행 (테스트 서버 제공) |
| 통합테스트 | 고객이 정의한 테스트 시나리오에 따라 병행 수행 |
| 결함관리 | 중요도 분류 → 원인 추적 → 재시험 → Close, 미해결 결함은 오픈 전 고객 협의·통제 |

## 5. 운영/유지보수 정책

- 무상 하자보수기간: 12개월
- 장애 발생 통보 후 2시간 이내 현장 도착 및 조치, 장애조치 결과 보고서 제출
- 인터페이스/배치는 고객 정의 표준(EAI 또는 ETL)에 준한 개발 수행, 결과 관리 기능 필수 반영

## 7. 프레임워크 관련 주의사항

> AP-Framework V0.43의 기본 배포 표준(Vercel/Supabase, Next.js API Routes 등)은 본 프로젝트에 적용하지 않는다. 위 2장의 PNDES 표준이 모든 산출물(시스템정의서, 인프라아키텍처, 코드)의 기준이다. 상세는 `CLAUDE.md`의 "Tech Stack — ⚠️ 프로젝트 커스텀" 섹션 참고.
