### TC-001. 조회조건별 부품 공정 자동화 현황 요약/상세 조회

| 항목 | 내용 |
|---|---|
| 관련 기능/요구사항 | F-001 |
| 사전조건 | 부품공정배치 원본 데이터 및 가공(집계) 테이블에 최소 1개 이상의 공장/라인 데이터가 동기화되어 있음 |
| 테스트 단계 | 1. 부품 공정 자동화 현황 화면 접속 2. 제품군/제품/권역/공장/라인 조회조건 선택 3. 조회 버튼 클릭 |
| 입력 데이터 | 제품군=A, 제품=A-1, 권역=국내, 공장=1공장, 라인=1라인 |
| 기대 결과 | 요약 현황(자동화율, 자동공정/총공정, 성인화 실적/계획, Best Practice·종합계) 및 공장/라인별 요약, 공정별 상세(NO/공정명/Best Practice/확대전개계획) 테이블과 첨부 미디어(자동화 설비 동영상 등)가 정상 표출됨 |
| 실제 결과 | (테스트 실행 후 기입) |
| 판정 | Pass / Fail (미실행) |

### TC-002. 조회조건 미선택 시 안내 메시지 표출

| 항목 | 내용 |
|---|---|
| 관련 기능/요구사항 | F-001 |
| 사전조건 | 부품 공정 자동화 현황 화면 접속 상태 |
| 테스트 단계 | 1. 부품 공정 자동화 현황 화면 접속 2. 조회조건을 선택하지 않고 조회 버튼 클릭 |
| 입력 데이터 | 조회조건 전체 미선택 |
| 기대 결과 | "조회조건을 선택해 주세요" 등 안내 메시지가 표출되고 조회가 실행되지 않음. 집계 데이터가 존재하지 않는 조건일 경우 "데이터 없음"이 표출되며, 원본(부품공정배치) 미동기화 시 최종 동기화 시각이 안내됨(NFR-008 연계) |
| 실제 결과 | (테스트 실행 후 기입) |
| 판정 | Pass / Fail (미실행) |

### TC-003. 부품 공정별 상세 등록/수정

| 항목 | 내용 |
|---|---|
| 관련 기능/요구사항 | F-002 |
| 사전조건 | 생기(생산기술) 업무 담당자 이상 권한으로 로그인, 등록 대상 부품 공정 존재 |
