# 데이터베이스 설계서 (kbt)

**프로젝트명**: PLM 생기포털 고도화 — 공정 자동화 현황 및 중장기 방향성 공유 신규 기능 구축
**작성일**: 2026-08-07
**최종 갱신일**: 2026-08-08 (kbt 검토 브랜치, 2차 갱신)
**버전**: v1.2-kbt
**DBMS**: Oracle 19.0 (온프레미스, Redhat Linux 8.10)
**근거 문서**: `02.기획문서/기능명세서_kbt.md`(F-001~F-019), `02.기획문서/화면설계서_kbt.md`(FLOW-MAP·DASH-AUTO·DASH-MTRM·MTRM-MAIN 포함 18개 화면), `02.기획문서/API스펙_kbt.md`(I/F 설계서, IF-001~IF-009)

> 본 문서는 공식 산출물 `데이터베이스설계서.md`(2026-08-07 확정)를 훼손하지 않는 별도 검토 브랜치입니다. Gate-Check/`.progress.md` 추적 대상이 아닙니다.
>
> **kbt 변경 이력(2026-08-08, 1차)**: FLOW-MAP·DASH-AUTO·DASH-MTRM 화면 신규 반영에 따른 **신규 테이블은 없습니다.** DASH-AUTO는 `TB_AUTO_PART_PROC`(F-001)·`TB_AUTO_MODULE_PROC`(F-005)·`TB_IF_EXEC_LOG`(F-009)를, DASH-MTRM은 `TB_MTRM_ROADMAP`/`TB_MTRM_ROADMAP_DETAIL`(F-010/F-011)·`TB_MTRM_COUNCIL`(F-016)·`TB_TECH_TREND`(F-019)를 **읽기 전용으로 재조회**할 뿐입니다(2절 ERD·1절 테이블 목록 변경 없음).
>
> **kbt 변경 이력(2026-08-08, 2차 — 변경 없음 확인)**: MTRM-MAIN은 `TB_MTRM_ROADMAP`/`TB_MTRM_ROADMAP_DETAIL`(F-010/F-011)·`TB_TECHPR_MATERIAL`(F-013)·`TB_TECH_TREND`(F-019)를 읽기 전용으로 재조회할 뿐 신규 테이블이 없습니다. SCR-012/014 등록 모달 필드 확정도 기존 테이블 컬럼 범위 내이므로 스키마 변경이 없습니다.

> 본 프로젝트는 현대모비스 생산기술포털(PNDES) 기존 시스템 증설 프로젝트입니다. **기존 부품공정배치·모듈공정배치 테이블(부품/모듈 원천 시스템 소유)은 본 설계서의 관리 대상이 아니며, 참조(읽기 전용) 관계만 표시**합니다. 본 문서는 신규로 추가되는 가공(집계) 테이블 및 mTRM/기술동향 등 신규 업무 테이블만 상세 정의합니다. 모든 컬럼 타입은 **Oracle 19.0 문법(VARCHAR2, NUMBER, DATE/TIMESTAMP, CLOB 등)**을 기준으로 하며, PK 컬럼은 `NUMBER GENERATED BY DEFAULT AS IDENTITY`(Oracle 12c+ IDENTITY 컬럼)를 사용합니다.

## 0. 원본(참조) 테이블 안내

| 원본 테이블 | 논리명 | 소유 시스템 | 연동 I/F | 본 프로젝트 처리 방식 |
|---|---|---|---|---|
| TB_PART_PROC_LAYOUT | 부품공정배치 | 부품공정배치 시스템(PNDES 내, 원본 시스템 소유) | IF-001 | 읽기 참조만, 야간 배치로 가공 테이블(TB_AUTO_PART_PROC)에 반영 |
| TB_MODULE_PROC_LAYOUT | 모듈공정배치 | 모듈공정배치 시스템(생기/생산, PNDES 내, 원본 시스템 소유) | IF-003 | 읽기 참조만, 배치+실시간 이벤트로 가공 테이블(TB_AUTO_MODULE_PROC)에 반영 |

> 위 2개 테이블은 컬럼 구조를 본 설계서에서 정의하지 않으며, ERD에는 연계 관계 표현을 위한 더미(참조용) 엔티티로만 표시합니다.

## 3. 테이블 정의

### 3.1 TB_AUTO_PART_PROC (부품공정 자동화현황)

관련 기능: F-001(조회), F-002(등록) / 관련 화면: SCR-001 / 관련 I/F: IF-001, IF-002

| 컬럼명 | 타입 | 제약조건 | 기본값 | 설명 |
|---|---|---|---|---|
| PART_PROC_ID | NUMBER | PK | GENERATED BY DEFAULT AS IDENTITY | 부품공정 자동화현황 ID |
| STD_PROC_ID | NUMBER | FK(TB_STD_PROC_MST), NOT NULL | - | 표준공정 ID |
| PROD_GRP_CD | VARCHAR2(20) | NOT NULL | - | 제품군 코드 |
| PROD_CD | VARCHAR2(20) | NOT NULL | - | 제품 코드 |
| REGION_CD | VARCHAR2(20) | NOT NULL | - | 권역 코드 |
| PLANT_CD | VARCHAR2(20) | NOT NULL | - | 공장 코드 |
| LINE_CD | VARCHAR2(20) | NOT NULL | - | 라인 코드 |
| PROC_NM | VARCHAR2(200) | NOT NULL | - | 공정명(비정규화, 조회 성능용) |
| AUTO_YN | CHAR(1) | NOT NULL, CHECK (AUTO_YN IN ('Y','N')) | 'N' | 자동(Y)/수동(N) 구분 |
| MANUAL_RSN | VARCHAR2(500) | NULL | - | 수동 사유(AUTO_YN='N'일 때) |
| BP_YN | CHAR(1) | NOT NULL, CHECK (BP_YN IN ('Y','N')) | 'N' | Best Practice 지정 여부 |
| BP_CONTENT | CLOB | NULL | - | Best Practice 상세 내용 |
| SHIFT_TYPE | VARCHAR2(50) | NULL | - | 교대운영(예: 2조2교대) |
| HEADCNT_DIRECT | NUMBER(6) | NULL | 0 | 총인원(직접) |
| SEONINHWA_ACT | NUMBER(6) | NULL | 0 | 성인화 실적 인원 |
| SEONINHWA_PLAN | NUMBER(6) | NULL | 0 | 성인화 계획 인원(IF-002 반영) |
| SYNC_DTTM | TIMESTAMP | NULL | - | 원본(IF-001) 최종 동기화 시각 |
| VALID_YN | CHAR(1) | NOT NULL, CHECK (VALID_YN IN ('Y','N')) | 'Y' | 정합성 검증 결과(NFR-008) |
| CREATED_BY | VARCHAR2(50) | NOT NULL | - | 등록자 |
| CREATED_DTTM | TIMESTAMP | NOT NULL | SYSTIMESTAMP | 등록일시 |
| UPDATED_BY | VARCHAR2(50) | NULL | - | 수정자 |
| UPDATED_DTTM | TIMESTAMP | NULL | - | 수정일시 |

### 3.2 TB_STD_PROC_MST (표준공정마스터)

관련 기능: F-003(등록/수정), F-004(조회/엑셀) / 관련 화면: SCR-002

| 컬럼명 | 타입 | 제약조건 | 기본값 | 설명 |
|---|---|---|---|---|
| STD_PROC_ID | NUMBER | PK | GENERATED BY DEFAULT AS IDENTITY | 표준공정 마스터 ID |
| PLANT_CD | VARCHAR2(20) | NOT NULL | - | 공장 코드 |
| LINE_CD | VARCHAR2(20) | NOT NULL | - | 라인 코드 |
| PROC_NM | VARCHAR2(200) | NOT NULL | - | 표준공정명 |
| PROC_SEQ | NUMBER(6) | NOT NULL | - | 공정 순서 |
| REMARK | VARCHAR2(500) | NULL | - | 비고 |
| USE_YN | CHAR(1) | NOT NULL, CHECK (USE_YN IN ('Y','N')) | 'Y' | 사용 여부 |
| CREATED_BY | VARCHAR2(50) | NOT NULL | - | 등록자 |
| CREATED_DTTM | TIMESTAMP | NOT NULL | SYSTIMESTAMP | 등록일시 |
| UPDATED_BY | VARCHAR2(50) | NULL | - | 수정자 |
| UPDATED_DTTM | TIMESTAMP | NULL | - | 수정일시 |

> 제약: `UNIQUE (PLANT_CD, LINE_CD, PROC_NM)` — 동일 공장/라인 내 공정명 중복 등록 차단(F-003 예외처리).

### 3.3 TB_AUTO_MODULE_PROC (모듈공정 자동화현황)

관련 기능: F-005(조회), F-006(연동 반영) / 관련 화면: SCR-003 / 관련 I/F: IF-003

| PROD_GRP_CD | VARCHAR2(20) | NOT NULL | - | 제품군 코드 |
| PROD_CD | VARCHAR2(20) | NOT NULL | - | 제품 코드 |
| PLANT_CD | VARCHAR2(20) | NOT NULL | - | 공장 코드 |
| LINE_CD | VARCHAR2(20) | NULL | - | 라인 코드 |
| MODULE_CD | VARCHAR2(20) | NOT NULL | - | 모듈 코드 |
| MODULE_NM | VARCHAR2(200) | NOT NULL | - | 모듈명 |
| AUTO_YN | CHAR(1) | NOT NULL, CHECK (AUTO_YN IN ('Y','N')) | 'N' | 자동(Y)/수동(N) 구분 |

### 3.4 TB_STD_TASK_NM (모듈표준작업명)

관련 기능: F-007(등록/삭제), F-008(연동 표출) / 관련 화면: SCR-004

| 컬럼명 | 타입 | 제약조건 | 기본값 | 설명 |

## 6. 데이터 정합성 정책 (원본 연동 → 가공 테이블 동기화)

| 항목 | 내용 |
|---|---|
| 대상 | TB_AUTO_PART_PROC(IF-001, IF-002 반영), TB_AUTO_MODULE_PROC(IF-003 반영) |
| 동기화 방식 | IF-001·IF-002: 야간 ETL 배치(1일 1회, 변경일시 기준 변경분 조회) / IF-003: ETL 배치(1일 1회, 전체 정합화) + EAI 실시간 이벤트(변경분 즉시 반영) |
| 처리 절차 | 1) 변경분 수신 2) 가공 테이블(TB_AUTO_PART_PROC/TB_AUTO_MODULE_PROC) UPSERT 3) 자동화율·성인화 등 집계값 재산출 4) `VALID_YN` 정합성 검증 플래그 갱신 5) `SYNC_DTTM`/`LAST_CHG_DTTM` 갱신 6) 결과를 TB_IF_EXEC_LOG에 기록 |
| 정합성 검증 기준 | 원본 건수 대비 가공 테이블 건수 일치 여부, 필수 키(제품군/제품/공장/라인/공정코드 등) NULL 여부, 자동/수동 구분값 유효성 |
| 불일치 처리 | `VALID_YN='N'`으로 표시 → 화면 상단 경고 배너 표출(SCR-001/003) → 관리자 확인 큐(TB_IF_EXEC_LOG.RESULT_CD='FAIL' 및 FAIL_RSN 기록) 등록 |
| 재시도 정책 | 원본 미접속·연동 실패 시 최대 3회 재시도(IF 공통정책) → 지속 실패 시 담당자 알림, TB_IF_EXEC_LOG에 재시도 이력(EXEC_TYPE_CD='재시도') 기록 |
| 근거 | API스펙.md IF-001~IF-003 처리절차/오류처리, 요구사항정의서 NFR-008 |
