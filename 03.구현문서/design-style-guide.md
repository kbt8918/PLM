# 디자인 스타일 가이드 (Design Style Guide)

**프로젝트명**: PLM 생기포털 고도화 — 공정 자동화 현황 및 중장기 방향성 공유 신규 기능 구축
**작성일**: 2026-08-07
**버전**: v1.0
**근거 문서**: `02.기획문서/화면설계서.md`(SCR-001~014), `02.기획문서/서비스기획서.md`

> **작성 원칙**: 본 문서는 신규 브랜드/신규 디자인 시스템을 정의하지 않습니다. 본 프로젝트는 현대모비스 생산기술포털(PNDES)이라는 **기존 전사 시스템 내 신규 메뉴 2건(공정 자동화 현황, mTRM)을 증설**하는 사내 SI 프로젝트이며(서비스기획서 5장 "브랜드 전략 — 해당 없음" 참고), 공통 헤더/GNB/사이드바/그리드/버튼/입력필드 등 **기본 UI 컴포넌트는 PNDES 기존 UI 표준을 그대로 준수**합니다. 이 문서는 신규 메뉴에서 **새로 추가되는 컴포넌트(자동/수동 매트릭스 셀, 상태 뱃지, 간트차트, 카드형 그리드 등)의 스타일만 상세 정의**하며, PNDES 기존 컬러 팔레트/폰트/아이콘 체계와 충돌하지 않는 범위 내에서 시맨틱 컬러를 보완합니다. 실제 값(정확한 Hex 코드 등)은 화면 퍼블리싱 단계에서 PNDES 공통 UI 컴포넌트 라이브러리 및 고객사 지원 인력과 최종 확정합니다.

## 1. 디자인 원칙

PNDES 기존 사용자(생기 업무 담당자, 공장/라인 현장 담당자, 생기기획팀 관리자)는 화면설계서 전반에서 확인되듯 **다수의 조회조건, 요약 테이블, 상세 매트릭스, 간트차트를 한 화면에서 동시에 다루는 데이터 밀도가 높은 업무 화면**을 사용합니다. 이에 따라 아래 4개 원칙을 정의합니다.

| # | 원칙 | 설명 | 화면설계서 근거 |
|---|------|------|------------------|
| 1 | **정보 신뢰성(Data Trust)** | 자동화 현황 데이터는 기존 부품/모듈 공정배치 데이터의 배치 연동 결과이므로, 화면 어디서나 "최종 동기화 시각"과 "정합성 경고" 상태를 숨기지 않고 노출한다 | SCR-001 빈 상태(최종 동기화 시각 안내), SCR-003 최종 연동 시각 배지·정합성 검증 실패 배너 |
| 2 | **일관성(Consistency)** | 조회조건 영역, 등록/수정 모달, 상태 뱃지, 빈 상태는 전 화면에서 동일한 패턴·컬러·간격을 사용하여 학습 비용을 최소화한다 | 3장 공통 컴포넌트 가이드(3.1~3.4) |
| 3 | **현장 가독성(Field Readability)** | 공장/라인 현장 담당자가 원거리·모니터 환경에서도 즉시 상태를 판별할 수 있도록, 자동/수동·성공/실패 등 핵심 상태는 색상만이 아니라 **아이콘/기호(●, X) + 텍스트**로 3중 코딩한다 | SCR-001 공정별 상세 매트릭스(●자동/X수동), SCR-005 실패 강조 |
| 4 | **관리자-사용자 구분 명확성(Role Clarity)** | 관리자 전용 화면(SCR-002/004/005/010/011/012)과 등록/수정/삭제 버튼은 일반 조회 화면과 시각적으로 구분되어, 권한 없는 사용자가 관리 기능으로 오인하지 않도록 한다 | 정보구조도 admin 스타일, 화면설계서 각 SCR "관리자만 노출" 규칙 |

## 2. 글로벌 레이아웃

### 2.1 기본 원칙

- 전 화면 **PC 전용, 1920px 데스크톱 고정 레이아웃**을 기준으로 하며 반응형 브레이크포인트는 정의하지 않습니다(화면설계서 전제 — 모바일 대상 아님).
- 헤더/GNB/좌측 메뉴 트리는 **PNDES 기존 공통 컴포넌트를 그대로 재사용**하며, 본 문서에서 신규로 정의하지 않습니다. 아래 표는 화면설계서의 실제 레이아웃(SCR-001 등)에서 관찰되는 공통 그리드/구획을 역산하여 신규 메뉴의 콘텐츠 영역 구성 기준으로 제시합니다.

### 2.2 페이지 레이아웃 구조 (1920px 기준)

```
+--------------------------------------------------------------------------------------------+  1920px
|  PNDES 공통 헤더 (H:60px) — 로고 / Breadcrumb(생기포털 > 대메뉴 > 소메뉴) / 사용자명 / 로그아웃  |
+------------+---------------------------------------------------------------------------------+
|            |  탭 영역 (H:44px, 화면에 탭이 있는 경우만: SCR-001/003)                            |
|  좌측 메뉴  +---------------------------------------------------------------------------------+
|  트리       |  조회조건 영역 (H:56px)                                                          |
|  (W:240px, |---------------------------------------------------------------------------------+
|  PNDES 공통)|  콘텐츠 영역 (fluid, 좌우 padding 24px)                                           |
|            |   - 요약 현황 (요약 카드/요약 테이블)                                              |
|            |   - 상세 목록/매트릭스/그리드/간트차트                                             |
+------------+---------------------------------------------------------------------------------+
```

| 영역 | 크기 | 비고 |
|------|------|------|
| PNDES 공통 헤더 | H: 60px, 전체 너비 | 기존 PNDES 표준 그대로 사용, 본 프로젝트에서 변경하지 않음 |
| 좌측 메뉴 트리 | W: 240px | 기존 PNDES 표준(생기포털 > 공정 자동화 현황 / 중장기 방향성 공유 2개 대메뉴 하위에 화면설계서 1장의 14개 화면 배치) |
| 탭 영역 | H: 44px | SCR-001(부품 공정/모듈 공정), SCR-003과 같이 동일 대메뉴 내 화면 전환에 사용. 신규 정의 |
| 조회조건 영역 | H: 56px, 콘텐츠 영역 상단 고정 | 3.1절 참고, 신규 정의 |
| 콘텐츠 영역 | Fluid (헤더+메뉴 제외 나머지 폭), 좌우 padding 24px | 요약/상세/그리드/간트 배치 |

### 2.3 콘텐츠 내부 그리드 · 스페이싱 (신규 정의)

화면설계서 SCR-001의 "조회조건 → 요약 현황 → 공정별 상세" 3단 구조를 기준으로 섹션 간 간격을 역산하여 정의합니다.

| 토큰 | 값 | 용도 |
|------|-----|------|
| spacing-xs | 4px | 뱃지 내부 텍스트-아이콘 간격, 매트릭스 셀 내부 여백 |
| spacing-sm | 8px | 조회조건 드롭다운 간 간격, 버튼 그룹 내 간격 |
| spacing-md | 16px | 테이블 셀 패딩, 카드 내부 패딩 |
| spacing-lg | 24px | 조회조건 영역 ↔ 요약 현황, 요약 현황 ↔ 상세 테이블 등 섹션 간 간격, 콘텐츠 영역 좌우 padding |
| spacing-xl | 32px | 탭 영역 ↔ 조회조건 영역 |
| 카드 그리드 컬럼 | 4열 (SCR-009 Tech PR, SCR-014 기술동향) | 1920px 콘텐츠 영역 기준, 카드 간 간격 24px |
| 테이블 열 정렬 | 좌측: 텍스트 / 우측: 숫자·비율(%) / 중앙: 상태·뱃지·매트릭스 셀 | SCR-001 요약 현황·상세 테이블 공통 |

## 3. 컬러 시스템

### 3.1 기본 원칙

- **PNDES 기존 브랜드 컬러 팔레트(Primary, Neutral/Gray Scale, 헤더/GNB 배경색 등)를 그대로 사용**합니다. 본 문서는 정확한 Hex 값을 알 수 없으므로 임의로 새 Primary 컬러를 정의하지 않으며, 화면 퍼블리싱 시 PNDES 공통 스타일시트(CSS 변수/클래스)를 그대로 상속받습니다.
- 아래는 **이번 신규 메뉴(공정 자동화 현황, mTRM)에서만 필요한 신규 시맨틱 컬러**입니다. PNDES 기존 시맨틱 컬러 체계(성공=초록/경고=주황/오류=빨강 계열 추정)와 충돌하지 않는 선에서, 화면설계서 3.3절 규칙을 기준으로 구체 톤을 지정합니다. 실제 Hex는 PNDES 기존 팔레트 확정 후 치환합니다.

### 3.2 자동/수동 매트릭스 셀 컬러 (SCR-001, SCR-003 신규)

| 상태 | 표기 | 텍스트/아이콘 색 | 배경색 | 용도 |
|------|------|------------------|--------|------|
| 자동 | ● (원형 아이콘 + "자동" 텍스트) | Green 계열 (#1E8E3E 또는 PNDES Success 색 대체) | Green 계열 10% 틴트 | 자동화 적용 공정/작업 |
| 수동 | X (X 아이콘 + "수동" 텍스트, 사유 존재 시 "수동(사유)") | Gray 계열 (#5F6368) | Gray 계열 5% 틴트 | 수동 공정/작업. 색상만으로 구분하지 않고 기호(●/X)를 항상 병기(원칙 3, 현장 가독성) |
| 데이터 없음 | "-" | Gray 300 | 없음(투명) | 해당 공장/라인에 데이터 미존재 |

> 자동/수동은 "성공/실패"의 의미가 아니므로 Success/Danger 컬러를 직접 재사용하지 않고 별도 시맨틱(Auto/Manual)으로 분리합니다. 색약 사용자를 고려해 기호(●/X) 병기를 필수로 합니다(8장 접근성 참고).

### 3.3 상태 뱃지 컬러 (화면설계서 3.3절 기준 구체화)

| 상태 | 컬러 그룹 | 텍스트/아이콘 | 배경 | 적용 화면 예 |
|------|-----------|---------------|------|--------------|
| 성공/완료/활성 | Success | Green 700 | Green 100 | SCR-005 실행결과(성공), SCR-011 발송완료, SCR-012 활성 |
| 진행중 | Info/Blue | Blue 700 | Blue 100 | SCR-006/007 로드맵·과제 진행중, SCR-008 간트 진행중 구간 |
| 대기(승인대기 등) | Warning/Orange | Orange 700 | Orange 100 | SCR-006 승인대기 |
| 실패/오류/차단 | Danger | Red 700 | Red 100 | SCR-005 실행결과(실패), SCR-011 발송 실패 |
| 보류/확인필요 | Neutral + 경고 아이콘 | Gray 700 | Gray 100 | SCR-003 정합성 검증 실패, SCR-013 매핑 보류 |

**뱃지 공통 스타일**: 높이 22px, 좌우 패딩 8px, border-radius 11px(pill), 좌측에 4px 도트 또는 12px 아이콘 + 4px 간격 + 텍스트(caption 크기). 색상 단독 사용 금지 — 모든 뱃지는 도트/아이콘을 함께 표시합니다.

### 3.4 간트차트 상태별 색상 (SCR-008, Highcharts Gantt)

| 계층 | 상태 | 막대 색상 | 비고 |
|------|------|-----------|------|
| 통합 로드맵(상위 막대) | 진행중 | Blue 500 | 상세과제 막대보다 진한 톤으로 계층 구분 |
| 통합 로드맵(상위 막대) | 승인대기 | Orange 400 | |
| 상세과제(하위 막대, 들여쓰기 표시) | 진행중 | Blue 300 | 상위보다 밝은 톤 |
| 상세과제(하위 막대) | 계획 | Gray 300, 대각 해칭 패턴(옵션) | 아직 시작 전 |
| 상세과제(하위 막대) | 완료 | Green 400 | |
| 오늘 날짜 기준선 | - | Red 300, 점선 1px | Highcharts plotLine으로 표현 |

### 3.5 관리자 전용 화면 구분색

| 구분 | 처리 | 대상 |
|------|------|------|
| 관리자 전용 상단 배지 | Breadcrumb 우측에 "관리자" 텍스트 뱃지(Gray 800 배경 + White 텍스트) 상시 노출 | SCR-002/004/005/010/011/012 (정보구조도 admin 스타일과 동일 기준) |
| 관리자 전용 액션(수정/삭제) | 비관리자에게는 컬럼 자체를 미노출(색상으로 숨기지 않고 DOM에서 제거) | SCR-002 관리 컬럼, SCR-012 CRUD 버튼 |

> 변경 이력(2026-08-20): 페이지 콘텐츠 좌측 컬러 바(3px, Gray 800)는 LNB 경계선과 시각적으로 겹쳐 과도하게 두꺼운 선으로 보이는 문제가 있어 제거했다. 관리자 전용 화면 구분은 상단 배지만으로 표시한다.

## 4. 타이포그래피

PNDES 기존 폰트 패밀리(고객사 표준 웹폰트, 예: 맑은 고딕/돋움 계열 추정)를 그대로 사용하며, 본 문서는 데이터 밀도가 높은 신규 화면에 필요한 타입 스케일만 정의합니다.

| 토큰 | 크기 | 행간 | 굵기 | 용도 |
|------|------|------|------|------|
| kpi-number | 28px | 34px | Bold | 요약 현황 요약카드/KPI 숫자(자동화율 %, 총인원 등) |
| table-header | 13px | 18px | SemiBold | 요약/상세 테이블 헤더(SCR-001~005 등 모든 DataTable) |
| table-cell | 13px | 20px | Regular | 테이블 셀 일반 텍스트 |
| table-cell-emphasis | 13px | 20px | SemiBold | Best Practice 행, 종합계 행 등 강조 셀 |
| matrix-cell | 13px | 18px | Medium | 자동/수동 매트릭스 셀(●/X + 텍스트) |
| badge-text | 12px | 16px | SemiBold | 상태 뱃지 텍스트 |
| gantt-label | 12px | 16px | Regular(상위) / Medium(하위 굵게 대비) | 간트차트 로드맵명/과제명 라벨 |
| card-title | 15px | 20px | SemiBold | 카드형 그리드 제목(Tech PR, 기술동향) |
| card-meta | 12px | 16px | Regular | 카드 메타정보(분과, 조회수, 작성일 등) |
| section-title | 16px | 22px | SemiBold | "요약 현황", "공정별 상세" 등 섹션 타이틀 |

### 4.1 사용 패턴

| 요소 | 적용 스타일 |
|------|-------------|
| 요약 현황 KPI 숫자(자동화율 등) | kpi-number + Semantic 색상(구간별: 70%↑ Green, 40~70% Orange, 40%↓ Red 등은 화면 확정 시 정의) |
| Best Practice 강조 행 | table-cell-emphasis + 행 배경 별도 틴트(5.1절 참고) |
| 매트릭스 셀(●/X) | matrix-cell, 중앙 정렬 |
| 관리자 전용 뱃지 텍스트 | badge-text + Gray 800 배경 대비 White |
| 빈 상태 안내문 | body(14px) + Gray 500 |

## 5. 핵심 신규 컴포넌트 스타일

### 5.1 조회조건 영역 (화면설계서 3.1 구체화)

```
+--------------------------------------------------------------------------------------------+
|  [드롭다운1] [드롭다운2] [드롭다운3] ...                                  [초기화] [조회]     |
+--------------------------------------------------------------------------------------------+
```

| 속성 | 값 |
|------|-----|
| 컨테이너 배경 | Gray 50(PNDES 기존 팔레트 값 상속) |

## 7. 인터랙션 & 모션

화면설계서에 명시된 인터랙션(종속 필터링, 모달, 토스트, 뱃지 색상 전환 등)에 대한 트랜지션 값을 정의합니다.

| 항목 | 트리거 | 효과 | 시간 |
|------|--------|------|------|
| 조건 종속 필터링 | 상위 드롭다운 선택 | 하위 드롭다운 옵션 fade 갱신 + 로딩 스피너 | 200ms |
| 모달 열기 | 등록/수정 버튼 클릭 | 오버레이 fade-in + 모달 scale(0.96→1) | 250ms |
| 모달 닫기 | X/취소/저장 완료 | fade-out + scale(1→0.96) | 150ms |
| 토스트 알림 | 등록/저장/발송 완료, 오류 | 우측 상단 slide-in, 3초 후 자동 slide-out | 300ms(진입) / 300ms(퇴장) |
| 상태 뱃지 색상 전환 | 상태값 변경(예: 발송중→발송완료) | 배경/텍스트 색 crossfade | 200ms |
| 매트릭스 셀 hover | mouse hover | 배경 8% 어둡게 | 100ms |
| 테이블 행 hover | mouse hover | 배경 Gray 50 전환 | 100ms |
| 탭 전환(부품/모듈 공정) | 클릭 | 콘텐츠 fade + 인디케이터 슬라이드 | 200ms |
| 간트 보기 전환 | 요약본/전체보기 라디오 선택 | 행 수 변경에 따른 높이 애니메이션 | 300ms |
| 정합성 경고 배너 | 배치 연동 결과 이상 감지 | 배너 slide-down (팝업/화면 상단) | 250ms |
| 삭제/차단 확인 모달 | 위험 액션 시도 | 모달 내 흔들림(shake) 없이 명시적 경고 텍스트만 강조(과도한 모션 지양) | - |

모든 트랜지션은 `ease-out`을 기본 timing function으로 사용하며, `prefers-reduced-motion` 설정 시 fade류를 제외한 이동/스케일 애니메이션은 생략합니다(8장 접근성 연계).
