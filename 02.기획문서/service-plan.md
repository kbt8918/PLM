## 1. Executive Summary

### 1.1 한 줄 요약

생기포털 내 부재했던 **공정 자동화 현황 공유 체계**와 **중장기 생산기술 로드맵(mTRM) 공유 체계**를 신규 구축하여, 공장/라인별 자동화 전개 현황과 중장기 기술 방향성을 전사에 공유한다.

### 1.2 핵심 지표

| 항목 | 내용 |
|------|------|
| 서비스명 | 생기포털 신규 메뉴 — ① 공정 자동화 현황, ② 중장기 방향성 공유(mTRM) |
| 목표 시장 | 해당 없음 (외부 시장 대상 상업 서비스가 아닌 사내 전사 시스템 증설) |
| 타겟 사용자 | 생기(생산기술) 업무 담당자, 공장/라인 현장 담당자, 분과 담당자 (착수보고서 §1 개요 기준) |
| 핵심 가치 | 자동화 전개 현황·우수사례(Best Practice)의 전사 공유, 분과별 중장기 로드맵의 체계적 관리·공유 |
| 수익 모델 | 해당 없음 (사내 IT 투자 프로젝트, 수익화 대상 아님) |
| 목표 기간 | 착수(2026-08-18) ~ 2차 오픈(2026-12-31) + 안정화 (착수보고서 §4) |

## 2. 서비스 배경 및 추진 배경

> 착수보고서에 마켓리서치/경쟁사 데이터가 없어, 이 장은 "시장 기회" 대신 착수보고서 §1(프로젝트 개요)에 기술된 **현행 시스템(AS-IS) 문제와 추진 배경**으로 구성했습니다.

### 2.1 현행 시스템(AS-IS) 현황

- 생산기술포털 내 **자동화 현황** 관련 기능이 부재하여, 공장/라인별 자동화 전개 현황 및 제약조건 극복 사례를 공유·관리할 체계가 없음
- **중장기 방향성 공유** 관련해서는 분과별 중장기 로드맵 현황·개정이력·진행 과제를 체계적으로 관리하는 기능과 제조기술 동향 공유 기능이 부재함

### 2.2 추진 배경 (필요성)

- 공정 자동화 현황을 시스템화하여 부품/모듈 공정별 자동화 적용 현황, 확대 전개 계획을 등록·조회·공유
- mTRM(통합/상세 로드맵, 협의체, Tech PR, 기술과제 연동, 기술동향)을 신규 구축하여 신기술 개발과 양산 적용 시점의 일관성 확보

### 2.3 시장 기회 / 경쟁 환경

해당 없음 — 사내 전사 시스템의 기능 증설이므로 외부 시장 진입이나 경쟁사 비교 대상이 존재하지 않습니다.

## 4. 서비스 전략

### 4.1 핵심 가치 제안 (Value Proposition)

생기포털 사용자에게 (1) 공장·라인 단위 자동화 현황을 한눈에 비교·조회할 수 있는 체계와 (2) 분과별 중장기 기술 로드맵을 간트 차트 형태로 관리·공유할 수 있는 체계를 제공하여, 자동화 확대 전개와 신기술 발굴·수평전개를 지원한다.

### 4.2 서비스 범위 (착수보고서 §3 그대로 반영)

| 구분 | 항목 | 우선순위 | 설명 |
|------|------|----------|------|
| 범위 내 | 부품 공정 자동화 현황 | P0 | 부품 공정별 현황 등록/조회, 공장별 비교 |
| 범위 내 | 공장 라인별 표준공정 마스터 | P0 | 표준공정 마스터 등록/조회, 엑셀 다운로드 |
| 범위 내 | 모듈 공정 자동화 현황 | P0 | 모듈공정배치와 상호 데이터 연동, 공장별 비교 |
| 범위 내 | 모듈 표준 작업명 관리 | P0 | 표준 작업명 등록/조회/삭제 |
| 범위 내 | 모듈공정배치 연동 | P0 | 생기/생산 모듈공정배치 데이터 인터페이스 |
| 범위 내 | mTRM 통합/상세 로드맵 | P0 | 등록/조회, 간트 차트 |
| 범위 내 | 생산기술 Tech PR (사용자/관리자) | P0 | 과제별 자료·동영상 그리드 조회, 메일 발송 |
| 범위 내 | mTRM 협의체/관리 | P0 | 협의체 등록/조회, 분과장 메일 발송 |
| 범위 내 | 기술과제 관리 연동 | P0 | 계획등록 시 mTRM 연동 |
| 범위 내 | 기술동향 | P0 | 글로벌 트렌드/신기술 자료 등록·조회 |
| 범위 외 | 시스템 개선 88건 (결재/프로젝트/조립공법서/기준정보 등) | - | 별도 트랙, 본 프로젝트 범위 아님 |
