## 2. Feature 1 — 공정 자동화 현황 (1차 오픈: 2026년 9월 말)

### F-001. 부품 공정 자동화 현황 조회

| 항목 | 내용 |
|---|---|
| 요구사항ID | REQ-001 |
| 설명 | 제품군/제품/권역/공장/라인 조건으로 부품 공정 자동화 현황을 조회하고, 공장/라인 간 비교 화면을 표출한다 |
| 입력 | 조회조건(제품군, 제품, 권역, 공장, 라인), 조회버튼 클릭 |
| 처리 | 1) 조회조건 유효성 검증 2) 가공(집계) 테이블에서 자동화율·자동공정/총공정·성인화 실적/계획 조회 3) Best Practice·종합계·공장/라인별 요약 산출 4) 공정별 상세(NO/공정명/Best Practice/확대전개계획) 조회 |
| 출력 | 요약 현황 테이블 + 공정별 상세 테이블, 자동화 설비 동영상 등 첨부 미디어 |
| 예외처리 | 조회조건 미선택 시 안내 메시지, 집계 데이터 없음 시 "데이터 없음" 표출, 원본(부품공정배치) 미동기화 시 최종 동기화 시각 안내(NFR-008) |
| 권한 | 전체 사용자(조회), 다운로드/이력은 로그인 사용자 대상 |
| 관련 화면 | 부품 공정 자동화 현황 화면, **(kbt)** DASH-AUTO 통합 대시보드(자동화율 요약 재사용) |

### F-002. 부품 공정별 상세 등록

| 항목 | 내용 |
|---|---|
| 요구사항ID | REQ-001 |
| 설명 | 개별 부품 공정건(공정명, Best Practice 내용, 공장/라인별 적용현황, 인원 등)을 등록/수정한다 |
| 입력 | 공정명, Best Practice 지정 여부·내용, 공장/라인별 적용현황(자동 ●/수동 X+사유), 인원, 첨부(동영상/이미지) |
| 처리 | 1) 입력값 검증(필수항목, 첨부 허용 확장자) 2) 기존 부품공정배치 데이터와의 정합성 체크 3) 등록/수정 반영 4) 이력 기록 |
| 출력 | 등록 완료 메시지, 갱신된 공정별 상세 테이블 |
| 예외처리 | 필수값 누락 시 저장 차단, 허용 확장자 외 첨부 시 업로드 차단(NFR-003), 부품공정배치 정합성 불일치 시 경고 후 관리자 확인 요청 |
| 권한 | 생기(생산기술) 업무 담당자 이상(등록/수정), 일반 사용자는 조회만 |
| 관련 화면 | 부품 공정 자동화 현황 화면(등록/수정 팝업) |

### F-003. 표준공정 마스터 등록/수정

| 항목 | 내용 |
|---|---|

| 설명 | 공장 라인별 표준공정 마스터 데이터를 등록/수정한다 |
| 입력 | 공장, 라인, 표준공정명, 공정 순서, 비고 |
| 처리 | 1) 입력값 검증 2) 동일 공장/라인 내 중복 공정명 체크 3) 등록/수정 반영 및 이력 기록 |
| 출력 | 등록 완료 메시지, 갱신된 표준공정 마스터 리스트 |

| 권한 | 생기기획팀(관리자) |
| 관련 화면 | 표준공정 마스터 관리 화면 |

### F-004. 표준공정 마스터 조회 및 엑셀 다운로드

| 항목 | 내용 |
|---|---|
| 요구사항ID | REQ-002 |
| 설명 | 공장/라인 조건으로 표준공정 마스터를 조회하고 리스트를 엑셀 파일로 다운로드한다 |
| 입력 | 조회조건(공장, 라인), 다운로드 버튼 클릭 |
| 처리 | 1) 조건별 리스트 조회 2) 엑셀 다운로드 요청 시 조회결과를 엑셀 포맷으로 변환·생성 3) 다운로드 이력 기록(NFR-003) |
| 출력 | 표준공정 마스터 리스트 화면, 엑셀 파일(.xlsx) |
| 예외처리 | 조회결과 없음 시 다운로드 버튼 비활성화, 다운로드 실패 시 재시도 안내 |
| 권한 | 전체 사용자(조회/다운로드) |
| 관련 화면 | 표준공정 마스터 관리 화면 |

| 항목 | 내용 |
|---|---|
| 요구사항ID | REQ-006 |
| 설명 | 분과별 통합 로드맵을 등록/조회하고 개정이력을 관리한다 |
