> 본 프로젝트는 현대모비스 PNDES 기존 시스템 증설이므로, CLAUDE.md 정의에 따라 RESTful API 스펙 대신 **PNDES 표준 I/F 설계서(EAI/ETL 방식)**로 #7 산출물을 대체합니다. PNDES 내부 화면 간 데이터 처리는 Java Spring 컨트롤러/서비스 계층에서 처리하며(상세는 `03.구현문서/시스템정의서.md` 참고), 본 문서는 **외부 시스템·PNDES 공통 기능과의 연동 인터페이스**만을 대상으로 합니다.
>
> 본 문서는 공식 산출물 `API스펙.md`(2026-08-07 확정)를 훼손하지 않는 별도 검토 브랜치입니다. Gate-Check/`.progress.md` 추적 대상이 아닙니다.
>
> **kbt 변경 이력(2026-08-08, 1차)**: FLOW-MAP·DASH-AUTO·DASH-MTRM 화면 신규 반영(`화면설계서_kbt.md`)에 따른 **신규 I/F는 없습니다.** DASH-AUTO/DASH-MTRM은 기존 IF-001(부품공정배치)·IF-003(모듈공정배치) 연동 결과로 생성된 가공 테이블을 SCR-001/SCR-003과 동일하게 조회할 뿐, 별도 연동을 추가하지 않습니다.
>
> **kbt 변경 이력(2026-08-08, 2차 — 변경 없음 확인)**: MTRM-MAIN 신규 화면, GNB 구성 정정, SCR-012/014 등록 모달 필드 확정 모두 신규 I/F 없이 기존 화면 조회 결과를 재사용하거나 화면 내부 폼 입력에 그치므로, 본 문서 내용은 1차본과 동일하게 유지합니다.

## 1. I/F 공통 사항

| 항목 | 내용 |
|---|---|
| 연동 표준 | 고객 정의 표준(EAI/ETL), PRD.md 부록 J 비기능요구사항 준수 |
| 연동 방식 | 실시간(EAI, 이벤트/API 기반) 또는 배치(ETL, 정기 스케줄) — I/F별 개별 지정 |
| 인터페이스 채널 | PNDES 내부망 EAI 솔루션 경유 또는 DB Link/배치 Job (고객사 인프라 정책에 따름) |
| 문자 인코딩 | UTF-8 |
| 인증 | PNDES 내부 시스템 간 연계는 접근 IP 화이트리스트 + 서비스 계정, 외부(메일 등)는 PNDES 공통 기능 자격증명 사용 |
| 오류처리 공통 정책 | 연동 실패 시 재처리 큐 등록(최대 3회 재시도) → 지속 실패 시 담당자 알림 → I/F 실행 결과(성공/실패) 이력 테이블에 기록(NFR-007) |
| 로깅 | 연동 요청/응답, 처리 건수, 실패 사유를 I/F 실행 이력 테이블에 기록, 조회 화면(F-009 관련) 제공 |

## 3. I/F 상세

### IF-001. 부품공정배치 데이터 연동

| 항목 | 내용 |
|---|---|
| 개요 | 부품 공정 자동화 현황(F-001) 산출에 필요한 부품공정배치 원본 데이터를 야간 배치로 수신하여 가공(집계) 테이블에 적재한다 |
| 연동구분 | 수신 (부품공정배치 → PLM 생기포털) |
| 연동방식 | ETL 배치 (Oracle DB Link 또는 배치 Job) |
| 주기 | 1일 1회 (야간, 세부 시각은 운영 협의) |
| 데이터 항목 | 제품군, 제품, 권역, 공장, 라인, 공정코드, 공정명, 자동/수동 구분, 적용일자, 변경일시 |
| 처리절차 | 1) 배치 Job 기동 2) 변경분(CDC 또는 변경일시 기준) 조회 3) 가공 테이블 갱신 4) 자동화율·성인화 집계값 재산출 5) 정합성 검증(NFR-008) |
| 오류처리 | 원본 미접속 시 재시도(최대 3회) → 지속 실패 시 담당자 알림, 정합성 불일치 발견 시 관리자 확인 큐 등록 |
| 관련 기능ID | F-001, F-002 |

| 오류처리 | IF-001과 동일 공통 정책 적용 |

| 데이터 항목 | 제품군, 제품, 공장, 모듈코드, 모듈명, 표준 작업명 코드, 자동/수동 구분, 변경일시 |
| 처리절차 | 1) 실시간 이벤트 수신 시 즉시 가공 테이블 갱신 2) 야간 배치로 누락분·전체 정합성 재검증 3) 표준 작업명(F-007/F-008) 매핑 반영 4) 실행 결과 기록(NFR-007) |
| 오류처리 | 이벤트 처리 실패 시 재처리 큐 등록, 배치 실패 시 재시도 후 담당자 알림, 정합성 불일치 시 F-006 검증 로그에 기록 |
