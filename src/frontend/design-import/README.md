갱신일: 2026-11-24 (통합 로드맵 차트 고도화)

## 파일
- `생기포털 v3.dc.html` — 최신 기준 소스 (헤더·GNB 메가메뉴·메인화면·전체 업무 화면·팝업, 단일 파일)
- `support.js`, `image-slot.js` — 실행에 필요한 런타임 (HTML과 같은 폴더에 둘 것)
- `SCREENS_INVENTORY.md` — 메뉴 구조, 화면 16개, 팝업 목록, 최근 바뀐 동작 (체크리스트)
- `CLAUDE_CODE_PROMPT.md` — Claude Code에 붙여넣을 요청문 (이번 변경분만 반영하는 버전 + 처음 반영하는 경우 문장)
- `CHANGES_2026-11-24.md` — 이번 변경 내역(통합 로드맵 차트)과 적용 체크리스트. 이전 변경은 `CHANGES_2026-10-24.md`
- 브라우저로 `생기포털 v3.dc.html`을 열면 화면과 인터랙션을 바로 확인할 수 있음

## 반영 방법
1. 이 폴더를 로컬 리포지토리 `src/frontend/design-import/` 에 복사 (기존 파일 덮어쓰기)
2. 커밋하고 올리기
   ```
   git add src/frontend/design-import
   git commit -m "생기포털 v3: 최신 화면 반영"
   git push
   ```
3. `CLAUDE_CODE_PROMPT.md` 내용을 Claude Code에 붙여넣기 (이미 반영한 적이 있으면 그 파일 하단의 "이후 디자인이 바뀌면" 문장 사용)

## 디자인 기준 요약
- 헤더: 흰색 2단(로고·유틸 / GNB 11개 메뉴), 폰트 Pretendard, 포인트색 `#1a4fb4`
- 업무 화면 팝업: 남색 제목 바(`#34437f`) + 우측 상단 작은 버튼, 폰트 맑은 고딕 11px, 표 라벨 셀 `#eef0f4`, 선 `#c3c9d4`
- 상세 색상·간격은 소스의 클래스/인라인 값이 기준입니다. 문서와 소스가 다르면 소스가 우선입니다.

## 참고
- 화면에 보이는 데이터는 모두 목업(샘플) 값입니다. 실제 서비스에서는 API 연동이 필요합니다.
- 이미지/동영상 자리는 `image-slot` 컴포넌트로 표시되며, 실제 서비스에서는 업로드된 파일로 대체해야 합니다.
- 이 문서는 소스에서 직접 확인한 메뉴·화면·팝업 목록 기준이며, 화면별 색상 상세표(이전 handoff README)는 포함하지 않습니다.
