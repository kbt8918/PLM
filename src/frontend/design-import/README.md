# Handoff: 생기포털(생산기술 자동화 관리 포털) 프로토타입

## Overview
차체/조립/도장/엔진/물류 등 각 공정의 자동화 현황, 표준공정 마스터, 중장기 자동화 로드맵, 생산기술 Tech PR, mTRM 협의체·관리, 기술과제, 기술동향을 하나의 포털에서 관리하는 사내 웹 애플리케이션 프로토타입.

## About the Design Files
`source/` 폴더의 `.dc.html` 파일은 **디자인 참고용 프로토타입**이며, 실제 프로덕션 코드로 그대로 복사해서는 안 됩니다. 이 문서와 스크린샷을 기준으로 대상 코드베이스의 기존 환경(React, Vue 등 이미 쓰고 있는 스택)과 기존 컴포넌트/스타일 패턴을 사용해 **재구현**하는 것이 목표입니다. 아직 프레임워크가 정해지지 않았다면 이 문서의 구조(사이드바 + 메인 컨텐츠 + 모달)에 가장 적합한 스택을 선택해 구현하세요.

`.dc.html` 파일은 브라우저에서 직접 열리는 단일 파일 컴포넌트 포맷으로, 실제 배포 스택과는 다릅니다. 인라인 스타일 값(색상 hex, px 값)만 정확한 참고 자료로 사용하세요.

## Fidelity
**High-fidelity (hifi)**: 최종 색상, 타이포그래피, 간격, 인터랙션이 반영된 목업입니다. 개발자는 대상 코드베이스의 기존 컴포넌트 라이브러리를 사용해 픽셀 단위로 최대한 유사하게 재현해야 합니다.

## Global Layout
- 좌측 고정 사이드바(LNB) 폭 약 260~280px, 배경 `#f8fafc`(연한 슬레이트), 우측 보더 `1px solid #e5e7eb`
- 상단 헤더: 브레드크럼(`생기포털 > 그룹명 > 화면명`) + 우측 상단 유틸 링크(업무프로세스 가이드 / 사용자명 / 로그아웃)
- 메인 컨텐츠 영역: 좌측 사이드바를 제외한 전체 너비, 흰색 배경, 여백 padding 20~24px
- 폰트: 시스템 산세리프(-apple-system, "Segoe UI", Roboto 등), 본문 11~12px, 타이틀(h2) 15~16px bold
- 주요 컬러: 브랜드 인디고/블루 계열 버튼(`#4f46e5` 유사), 성공(초록), 실패(빨강), 경고(주황), 중립 텍스트 `#374151`/`#6b7280`/`#9ca3af`
- 상태 뱃지(칩): 진행중/계획/완료/반려/보류 등 상태별 컬러 배지, radius 4~6px, 얇은 배경색 + 진한 텍스트

## 좌측 메뉴 구조 (LNB)
```
공정 자동화 현황
 ├ 부품 공정 자동화 현황
 ├ 표준공정 마스터 관리 (A)
 ├ 모듈 공정 자동화 현황
 ├ 모듈 표준 작업명 관리 (A)
 └ I/F 실행결과 관리 (A)

중장기 방향성 공유
 ├ 메인 대시보드
 └ 통합 로드맵 (아코디언, 하위 2개)
     ├ 상세과제 로드맵 관리
     └ 통합 로드맵 차트

생산기술 Tech PR
 ├ 생산기술 Tech PR
 ├ 생산기술 Tech PR 관리자 (A)
 ├ mTRM 협의체 (A)
 ├ mTRM 관리 (A)
 ├ 기술과제 관리 (A)
 └ 기술동향
```
"(A)" 뱃지는 관리자 전용 메뉴 표시. "통합 로드맵" 클릭 시 아코디언이 열리고 하위 항목이 슬라이드 다운.

## Screens / Views

### 1. 부품 공정 자동화 현황 (screenshots/01)
- **Purpose**: 공정별/공장·라인별 자동화율, 직접인원 현재→개선 수치를 요약 테이블로 조회
- **Layout**: 상단 탭(부품 공정 / 모듈 공정), 필터 바(제품군/제품/지역/공장/라인 드롭다운 + 조회 버튼), 하단 가로 스크롤 요약 테이블(공정 열 고정 + 라인별 컬럼)
- **Components**: 셀 안에 "72%→94% (22%▲)" 형태로 증감 표시(빨간 화살표), 자동화 상태는 "● 자동" 텍스트 또는 "X(기술)" 형태
- **Interaction**: 탭 전환, 필터 변경 후 조회 클릭 시 토스트 알림

### 2. 표준공정 마스터 관리 (02) — 관리자
- **Purpose**: 공장/라인별 표준공정 등록 순서 관리
- **Layout**: 필터 바(공장/라인/표준공정명/순서/비고) + 액션 버튼(엑셀 다운로드, +표준공정 등록), 하단 테이블(NO/공장/라인/표준공정명/순서/비고/관리)
- **Interaction**: 행별 수정/삭제 버튼, +등록 버튼 클릭 시 등록 모달 오픈, 페이지네이션

### 3. 모듈 공정 자동화 현황 (03)
- **Layout**: 탭(부품 공정/모듈 공정) + 최종 동기화 시각 표시, 필터 바, 정합성 검증 실패 경고 배너(주황), 요약 현황 테이블(공장/차종별)

### 4. 모듈 표준 작업명 관리 (04) — 관리자
- **Layout**: 필터(공정유형/표준작업명/사용현황/등록일) + 등록 버튼, 테이블(NO/표준작업명/공정유형/사용현황(연동모듈수)/등록일/관리)
- 사용현황 숫자는 링크 스타일(파란색)로 연동된 모듈 수 표시

### 5. I/F 실행결과 관리 (05) — 관리자
- **Layout**: 기간(시작~종료) + I/F 유형 + 결과 필터, 테이블(NO/실행시각/I/F-ID/유형/처리건수/결과/실패원인)
- 결과 컬럼은 "성공"(초록 배지)/"실패"(빨강 배지) 칩으로 표시

### 6. 메인 대시보드 (06)
- **Purpose**: 통합 로드맵 · 생산기술 Tech PR · 기술동향을 한 화면에서 요약
- **Layout**: 상단 KPI 카드 5개(등록 로드맵/진행중/계획/반려/보류, 상단 컬러 도트+숫자), 통합 로드맵 간트 미니뷰(로드맵명 + 분기별 바), 하단 2단 그리드(Tech PR 리스트 / 기술동향 카드)
- **Interaction**: KPI 카드 클릭 시 해당 상태로 필터링된 통합 로드맵 화면으로 이동, 로드맵 바 클릭 시 상세과제 로드맵 관리로 이동

### 7. 통합 로드맵 (07)
- **Layout**: KPI 카드 5개(메인 대시보드와 동일 스타일) + 필터 바(분과/로드맵명/기간/상태 + 대표과제 검색) + "간트차트로 보기" 링크 + 테이블(NO/분과/로드맵명/기간/대표과제/상태/개정이력)
- **Interaction**: "+로드맵 등록" 버튼 → 등록 모달, 행 클릭 시 상세 이동

### 8. 상세과제 로드맵 관리 (08)
- **Layout**: 필터(통합 로드맵/담당자/기간/진행상태) + "+상세과제 등록" 버튼(우측 상단), 테이블(NO/과제명/담당자/기간/진행상태/관리)
- **Interaction**: 진행상태 배지 컬러(진행중=파랑, 계획=주황 등), 등록 버튼 클릭 시 상세과제 등록 팝업(과제명/담당자/기간(시작~종료)/연동 로드맵)

### 9. 통합 로드맵 차트 (09)
- **Layout**: 필터(분과/기간범위) + 범례(차체/조립 등 컬러 도트) + 뷰 토글(요약본/전체보기, 선택된 쪽 진하게), 하단 간트차트(좌측 로드맵/과제명 고정열 + 우측 분기별(26.Q1~28.Q4) 그리드, 막대는 로드맵별 지정 컬러)
- **Interaction**: 가로 스크롤로 분기 이동, 막대 클릭 시 상세 팝업(과제명/담당자/기간)

### 10. 생산기술 Tech PR (10)
- **Layout**: 필터(제목 검색) + "기술 문의/제안" 버튼(우측 상단, 강조색), 카드 그리드(5열), 각 카드는 썸네일(동영상/파일/텍스트/복합자료 타입별 아이콘) + 타입 배지 + 제목 + 부서·날짜
- **Interaction**: 카드 클릭 시 상세 팝업(설명문구 항상 노출), 하단 페이지네이션

### 11. 생산기술 Tech PR 관리자 (11)
- **Layout**: 필터(제목/과제/담당자/첨부검색/등록일) + "+자료 등록" 버튼, 테이블(NO/제목/과제/담당자/첨부(문서/동영상)/등록일/관리)

### 12. mTRM 협의체 (12) — 관리자
- **Layout**: 필터(협의체명/분과/의제/대상 분과장/등록일/상태) + "+협의체 등록" 버튼, 테이블(NO/협의체명/분과/의제/대상 분과장/일정/메일상태)
- 메일상태 배지: 발송완료(초록)/발송대기(회색)

### 13. mTRM 관리 (13) — 관리자
- **Layout**: 필터(mTRM명/분과/상태/등록일) + "+mTRM 등록" 버튼, 테이블(NO/mTRM명/분과/상태/등록일/관리)
- 상태 배지: 활성(초록)/비활성(회색)

### 14. 기술과제 관리 (14) — 관리자
- **Purpose**: mTRM 로드맵과 연동되는 기술과제를 폼 방식으로 등록
- **Layout**: 상단 기본정보 폼(과제명*/담당자*/계획등록일*, 2열 그리드) → 구분선 → "mTRM 연동 영역"(연동 mTRM 로드맵 셀렉트) → "자동 매핑 결과" 테이블(매핑 로드맵명/매핑 상세과제/매핑상태, 로드맵 미선택 시 안내 문구) → 하단 취소/등록 버튼(우측 정렬)

### 15. 기술동향 (15)
- **Layout**: 필터(제목 검색) + 관리자용 "수정"/"+등록" 버튼, 카드 그리드(5열), 각 카드는 재생 아이콘 썸네일 + 제목 + 조회수 + 등록일
- **Interaction**: 카드 클릭 시 상세 팝업(설명문구 항상 노출, 있을 때만이 아니라 모든 카드에 공통 표시), 등록 버튼 클릭 시 등록 폼(제목/담당자 이름/부서명/태그/내용)

### 16. 업무프로세스 가이드 (16)
- **Purpose**: 통합 로드맵 → mTRM 관리 → mTRM 협의체 → 기술과제 관리 간 데이터 흐름을 설명하는 참고 문서 화면
- **Layout**: 5단계 스텝 카드(STEP 1~5, 각 담당자 역할 + 화면명), 순환 구조 설명 문단, 하단 "기능 정의 확인 필요 항목" 테이블(영역/메뉴 | 확인 필요 내용)

## Interactions & Behavior (공통)

### 화면 전환
- 좌측 LNB 메뉴 클릭 → `activeView` 상태값 변경 → 메인 영역 즉시 스위칭(라우팅 없이 SPA 내부 state 전환), 헤더 브레드크럼(`생기포털 > 그룹명 > 화면명`) 동시 갱신
- "통합 로드맵" 부모 메뉴는 클릭 시 화면 이동 없이 아코디언만 토글(펼침/접힘, chevron 아이콘 회전). 하위 화면(상세과제 로드맵 관리/통합 로드맵 차트) 진입 시 부모 아코디언 자동 펼침 유지
- KPI 카드 클릭 → 상태값을 필터로 미리 세팅한 채 "통합 로드맵" 화면으로 이동(예: "반려" 카드 클릭 시 상태 필터 = 반려로 세팅된 통합 로드맵 목록 노출)

### 필터 / 조회
- 드롭다운·검색어 입력은 즉시 상태(state)에 반영, "조회" 버튼(accent-600 배경, 흰 텍스트) 클릭 시 필터 조건으로 목록 재계산
- 조회 완료 시 화면 우상단 토스트 알림 노출(2~3초 후 자동 소멸)

### 모달 / 팝업
- 등록 버튼(`+ 등록`, `+ 표준공정 등록` 등, accent-600 배경) 클릭 → `modalOpen=true`, 오버레이 `background: rgba(15,23,42,0.5)`, `position:fixed; inset:0`, `z-index` 최상단
- 모달 패널: 흰 배경, `rounded-lg`, 헤더(제목 + X 닫기 아이콘) / 바디(폼 필드) / 푸터(취소·저장 버튼, 우측 정렬) 3단 구조
- 오버레이 클릭 또는 헤더의 X 버튼, 푸터의 "취소" 클릭 시 닫힘. 모달 패널 내부 클릭은 `stopPropagation`으로 오버레이 클릭과 분리되어 닫히지 않음
- 카드 클릭형 상세 팝업(Tech PR/기술동향)은 등록 폼이 아닌 읽기 전용 상세 뷰: 제목/메타정보/썸네일/설명문구가 항상 노출(설명문구 유무와 무관하게 동일 레이아웃 유지)
- 상세과제 등록, 표준공정 등록, mTRM 등록 등 각 등록 모달은 화면별로 필드 구성만 다르고 오픈/클로즈 로직은 동일 패턴 재사용

### 상태 변경 / 배지
- 상태값(진행중/계획/반려/보류/완료/활성/비활성/성공/실패)마다 위 Design Tokens 표의 고정 배경·텍스트 컬러 매핑을 사용해 배지(`rounded-full`) 렌더링
- 등록/수정 폼 저장 시 목록의 해당 행 상태가 즉시 갱신되고 배지 컬러도 함께 전환

### 테이블 행 액션
- 각 행 우측 "관리" 컬럼에 수정(테두리 버튼)/삭제(빨강 텍스트) 액션 배치
- 삭제 클릭 시 확인 후 목록에서 제거, 수정 클릭 시 해당 행 데이터가 채워진 등록 모달과 동일한 폼이 오픈(등록/수정 모달 공용)

### 페이지네이션

### Typography
- Font family: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- 화면 타이틀(h2): `text-lg font-bold` (18px/700) 색상 `#111827`
- 서브텍스트: `text-[11px] text-gray-500` (`#57606b`)
- 테이블 헤더: `text-xs font-semibold` (12px)
- 테이블 셀: `text-sm`~`text-xs` (12~14px)
- 배지 텍스트: `text-[10px]`~`text-xs font-semibold`
- 카드 제목: `text-sm font-semibold`

### Spacing / Radius
- 필터바 요소 간 `gap-2`(8px), 필터바와 하단 컨텐츠 간 `mb-4`(16px)~`mb-6`(24px)
- 카드 그리드 `gap-4`(16px), 5열 그리드
- 테이블 셀 padding `px-3 py-2` (12px/8px)
- 카드/모달/버튼/인풋 공통 radius: `rounded`(4px)~`rounded-lg`(8px), 배지는 `rounded-full`
- 카드: `shadow-sm border border-gray-200`, hover 시 `shadow-md`
- 카드 썸네일 로딩 플레이스홀더 패턴: `repeating-linear-gradient(45deg, #f1f5f9, #f1f5f9 Npx, #e5e7eb Npx, #e5e7eb 2Npx)` (동영상/이미지 자료 없음을 나타내는 사선 패턴, 카드형 8px, 상세형 10px 간격)

## Assets
별도 이미지 리소스 없음. 카드 썸네일은 자료 유형별 아이콘(재생 아이콘/파일 아이콘)으로 대체된 플레이스홀더입니다. 실제 자료(동영상/문서 파일, 실제 카드 이미지)는 개발 시 확보 필요.

## State Management
- `activeView`: 현재 선택된 메뉴/화면 id (문자열)
- `roadmapOpen`: 통합 로드맵 아코디언 펼침 여부 (boolean)
- `modalOpen` / 각 화면별 등록·상세 모달 오픈 상태
- 화면별 `filter` 객체(선택된 드롭다운/검색어 값)
- `page`: 목록 화면의 현재 페이지 번호
- 실제 서비스에서는 각 화면의 목록/상세/필터 옵션 데이터를 서버 API로 대체 필요 (본 프로토타입은 하드코딩된 목업 데이터 사용)
