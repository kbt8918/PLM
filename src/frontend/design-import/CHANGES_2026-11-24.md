# 변경 내역 — 2026-11-24 (통합 로드맵 차트 고도화)

대상 화면: **통합 로드맵(mTRM) 차트** 한 화면. 다른 화면은 2026-10-24 이후 변경 없음.
소스: `생기포털 v3.dc.html` 의 `VIEW: 통합 로드맵 개요` 블록과 `RM_LANES` 데이터, `rmLanes`/`rmRange` 로직.

## 1. 필터 영역
- 분과 / 진행상태 / 기간을 회색 라벨 셀(`#eef0f3`) + 입력 셀 형태로 한 줄 구성
- 기간은 연도 2칸(기본 2025 ~ 2030). **조회 버튼을 눌러야 차트에 적용** (입력만 바꾸면 적용 안 됨). 범위 2025~2030, 시작 > 종료이면 종료를 시작에 맞춤
- 우측: "상세검색"(기존 상세조회 버튼 이름 변경) + "조회"(어두운 버튼). mTRM / 기술과제 체크박스 유지
- 범례: mTRM 로드맵(청록) / 상세과제 기간(초록, 단일색) / 완료 단계(초록 마름모) / 예정 단계(흰 마름모) / 오늘. 상세과제 색 구분(초록·주황) 및 로드맵 그룹 박스 색은 **없음**

## 2. 차트 격자
- 분기/월 토글(선택 탭 파란색). **차트 폭은 두 보기 모두 1800px 고정**, 넘치면 가로 스크롤. 분과 이름 칸과 좌상단 모서리는 가로 스크롤 시 왼쪽 고정(sticky)
- 내부 격자는 항상 6년 = 72개월 컬럼. 막대 위치는 월 단위로 계산 (분기 데이터는 ×3)
- **조회 기간이 짧아도 칸 폭은 6년 기본과 동일.** 조회 기간 밖은 헤더·분기/월 칸·세로선 없이 빈 공간으로 둠. 기간 밖 막대는 숨기고, 기간 경계에 걸친 막대는 경계에서 잘림. 오늘선도 기간 밖이면 숨김
- 헤더: 연도 행(`#5b656f`, 흰 글자) + 분기/월 행. 분과 칸 `#dfe3e7`, 분과 미매핑 행은 사선 무늬 회색

## 3. 막대 구성
- 로드맵 막대: 청록 `#2fa4b5`, 높이 20px, 라운드, 가운데 흰 글자
- 상세과제 막대: 초록 `#12842f`, 높이 8px. 막대 위에 제목
- 분과마다 로드맵 막대 1개 이상, 그 아래 줄에 연계 상세과제 막대
- 분과 매핑이 없는 상세과제는 맨 아래 "분과 미매핑 / 연계 분과 없음" 행에 표시
- 같은 분과의 서로 다른 기간 과제·로드맵은 **겹치지 않으면 한 줄에 옆으로 나열** (데이터의 `row` 값이 같으면 같은 줄)
- 로드맵보다 기간이 길거나 로드맵 이후에 시작하는 상세과제도 해당 분과에 그대로 표시
- 월 단위 데이터는 `m: { start, span }` (2025-01 = 1). 없으면 분기 `start/span`

## 4. 진행상태(P1~P4) 표시 — 핵심 규칙
- P1 계획 일정 등록(계획 시작·완료일정 → 이 기간이 막대), P2 실적(계획) 시작일정 등록, P3 실적(완료) 일정 등록, P4 양산 적용 계획 체크
- **P1~P3은 모든 상세과제에 표시**. P4는 특수 케이스(`p4: true`)에만 표시
- 완료 단계(`milestones`)는 초록 마름모를 **막대 왼쪽에 순서대로** 모으고, 막대는 그 오른쪽. 남은 단계는 흰 마름모를 막대 오른쪽 끝에 연결선과 함께 표시. `milestones` 없으면 P1만 완료로 처리
- 막대 기간이 1분기 이하이거나, 같은 줄 뒤따르는 과제와 단계 표시가 겹치면 그 과제의 단계 마름모를 **막대 바로 아래 줄**에 P1-P2-P3(-P4) 순으로 나열 (제목은 잘리지 않게 한 줄)

## 5. 마우스 오버 (상세과제 막대)
- 계획일정(막대 시작일) / 완료일정(막대 종료일) / 등록일
- 진행상태 표: P1 계획 일정 등록 = 기간, P2 실적(계획) 시작일정 등록 = "시작일 YYYY-MM-01" 또는 "미등록", P3 실적(완료) 등록 = "완료일 YYYY-MM-DD" 또는 "미등록", P4 양산 적용 체크 = "양산 적용 확인" / "체크 대기"(P4 있는 과제만)
- 현재는 목업이라 P2 시작일은 막대 시작일을 그대로 사용. 실제로는 P2·P3 일자 필드를 별도로 받아야 함
