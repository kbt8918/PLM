## 통합 로드맵 (mTRM) 화면 변경
- **상단 "버전" 영역 삭제**. 우측 상단에는 "업데이트일자"만 남김
- **업데이트일자 드롭다운(커스텀)**: 처음에는 최근 업데이트 일자(2021-10-19 15:30:25) 표시 → 누르면 아래로 날짜 목록(2021-10-19 15:30:25 / 2021-07-02 10:12:08) → **목록의 날짜를 선택할 때만** mTRM 업데이트 이력 팝업이 열리고, 업데이트일자 칸에는 방금 고른 날짜가 표시됨. 날짜 칸만 눌러 목록을 열고 닫는 동안에는 팝업 없음. 팝업 내용은 날짜와 관계없이 동일(날짜별 필터 없음). 목록 바깥 클릭으로 닫히는 동작은 없음(날짜 칸 재클릭으로 닫음)
- **상세조회 안의 "버전" 셀렉트는 그대로 유지**(Ver. 1 현재 / Ver. 0 선택 시 이전 버전 표시·노란 배너·변경내용 팝업). 이전 버전을 볼 수 있는 유일한 입구
