NO상세설명
1 영역명: 탭 영역
ㄴ 부품 공정 / 모듈 공정 탭으로 공정 유형을 전환하는 영역이다. 요소 2종(부품 공정 탭, 모듈 공정 탭)으로 구성된다.

요소: 1-1 부품 공정 탭
노출조건: 화면 진입 시 항상 표시. 기본 활성 탭.
입력조건: 클릭 시 활성화. 활성화되면 하단 요약 현황·공정별 상세 표가 부품 공정 데이터로 갱신.
출력조건: 활성 시 다크 배경의 필 형태로 강조 표시.
인터랙션: 탭 전환 시 하단 콘텐츠 페이드 전환.

요소: 1-2 모듈 공정 탭
노출조건: 화면 진입 시 항상 표시.
입력조건: 클릭 시 활성화, 하단 표가 모듈 공정 데이터로 갱신.
출력조건: 비활성 시 회색 텍스트로 표시.
인터랙션: 탭 전환 시 하단 콘텐츠 페이드 전환.
2 영역명: 필터 영역
ㄴ 제품군/제품/지역/공정/라인 5종 셀렉트 필터와 조회 버튼으로 구성된 조건 필터 영역이다.

요소: 조건 필터 & 조회 버튼
노출조건: 항상 표시. 기본값은 전체(전체 라인 조회).
입력조건: 상위(제품군) 선택 시 하위(제품/지역/공정/라인) 옵션이 연동되어 변경. 조회 버튼 클릭 시 하단 표(요약 현황/공정별 상세) 갱신.
예외 Case:
· 조회 결과 데이터 없음 → alert: "조회된 데이터가 없습니다."
· 네트워크 오류 시 → toast: "잠시 후 다시 시도해주세요."
BE 연동: GET /api/automation/parts/summary?factory=&line=®ion=&product=&group=
3 영역명: 요약 현황
ㄴ 라인별 자동화율/직접인원/완료일정을 비교하는 요약 매트릭스 표이다.

3 요소: 요약 현황 표
노출조건: 필터 조회 결과에 따라 라인 컬럼이 동적으로 구성.
출력조건: 자동화율은 "현재% → 목표%(증감폭)", 직접인원은 "현재명 → 목표명(감소폭)" 형식으로 표시. [B/P] 창원2C 라인 컬럼은 기준(베이스라인)으로 강조 표시.
BE 연동: 부품/모듈 공정배치 원천 데이터 집계 배치 결과를 조회(GET /api/automation/parts/summary).
4 영역명: 상세 영역
ㄴ 공정 단위로 현재/개선 상태와 라인별 확대(전개/계획) 현황을 표시하는 상세 매트릭스 표이다.

요소: 공정별 상세 표
노출조건: 필터 조회 시 공정 목록과 라인 컬럼이 함께 갱신.
출력조건: 셀 값은 "●자동/수동" 표기, "가능('연도)", "협의필(ROI·회수불가 사유) N명", "미적용(사유)" 등 상태별 표기 규칙을 따른다.
인터랙션: 행(공정) 클릭 시 상세 이력/특성 팝업 오픈(연계 화면, 본 샘플 범위 외).
관리자 화면 연동: 신규 공정 등록 시 표준공정 마스터 관리 목록에 반영.
BE 연동: GET /api/automation/parts/process-detail
5 영역명: CTA 영역
ㄴ 공정별 상세 표에 대한 데이터 등록·내보내기·공유 액션 버튼 3종으로 구성된 영역이다.

요소: 5-1 + 공정 등록 버튼
노출조건: 공정별 상세 표 상단 우측에 항상 표시.
입력조건: 클릭 시 공정 등록 팝업 오픈.
예외 Case: 필수값 누락 → alert: "필수 항목을 입력해주세요."
BE 연동: POST /api/automation/parts/process

요소: 5-2 엑셀 버튼
노출조건: 공정별 상세 표 상단 우측에 항상 표시.
입력조건: 클릭 시 현재 조회 결과를 xlsx로 다운로드.
예외 Case: 다운로드 대상 데이터 없음 → alert: "다운로드할 데이터가 없습니다."
BE 연동: GET /api/automation/parts/export
