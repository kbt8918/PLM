노출조건: DASH-AUTO 진입 시 항상 표시.
2카드 영역요약 지표 KPI 카드 5종전체/부품공정/모듈공정 자동화율, 등록 표준공정 건수, I/F 최근 실패 건수.

출력조건: I/F 최근 실패 등 위험 지표는 danger 색상(빨강) 강조.
BE 연동: IF-001·IF-003 배치 결과 기반 가공 테이블 집계값 조회.
3카드 영역부품 공정 — 공장/라인별 자동화율 패널SCR-001 요약현황(자동화율 행)을 그대로 재사용해 실시간 계산되는 막대그래프.

출력조건: 70% 이상 녹색, 40~69% 주황, 40% 미만 빨강 색상 구간화.
인터랙션: 우측 상단 '부품 공정 ›' 클릭 시 SCR-001로 이동.
BE 연동: F-001 부품 공정 자동화 현황 조회 결과와 동일 소스.
4카드 영역모듈 공정 — 차종별 자동공정/총공정 패널SCR-003 요약현황('자동공정 / 총 공정' 행)에서 실시간 계산되는 막대그래프.

출력조건: 자동공정/총공정 비율(%)로 막대 길이 산출, 우측에 'N/N' 표기.
인터랙션: 우측 상단 '모듈 공정 ›' 클릭 시 SCR-003으로 이동.
BE 연동: F-005 모듈 공정 자동화 현황 조회 결과와 동일 소스(IF-003).
5카드 영역전체 자동화율 도넛 차트부품 공정 자동화율 평균을 도넛 차트로 표시 + 모듈 조립 직접인원 합계.

출력조건: 중앙에 평균 자동화율(%) 숫자 표기.
6카드 영역공정별 상세 매트릭스 — 자동/수동 비율SCR-001 공정별 상세의 '현재' 상태를 집계한 자동/수동 비율 바 + 범례.

출력조건: 자동(녹색)/수동(회색) 비율 및 건수 동시 표기.
7카드 영역최근 I/F 실행결과 패널SCR-005 I/F 실행결과 관리의 최근 3건을 요약 표시(실행시각/I/F-ID/결과 배지).

출력조건: 성공(녹색)/실패(빨강) 배지.
관리자 화면 연동: SCR-005(I/F 실행결과 관리, 관리자 전용)와 동일 데이터 소스 공유.
BE 연동: IF-003 모듈공정배치 연동 실행 결과 이력 조회(NFR-007).
8카드 영역중장기 확대 전개 로드맵(4열 카드)라인별 확대 전개 진행률(진행중/계획 배지 + 진행률 바 + 목표 완료연도).

인터랙션: 우측 상단 '상세 보기 ›' 클릭 시 SCR-001로 이동.
9카드 영역바로가기 그리드공정 자동화 현황 그룹 내 5개 화면(SCR-001~005) 바로가기 카드.

입력조건: 카드 클릭 시 해당 화면으로 이동.
10내비 영역좌측 GNB 메뉴공정 자동화 현황/중장기 방향성 공유 전체 메뉴 트리 — 전체 구조 참고용으로 최초 화면(DASH-AUTO)에서만 노출.

노출조건: 이후 31개 화면은 화면 콘텐츠 표시 영역 확보를 위해 GNB를 생략(본 화면과 동일 메뉴 트리 반복 노출 방지).
