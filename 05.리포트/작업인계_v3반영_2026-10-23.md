### C. GNB 확장 (B와 함께)

`src/frontend/js/config.js` 교체 대상:
- 1차 메뉴에 `auto`(자동화 현황), `share`(생산제조기술 공유) 추가
- `method`에 `layout: 'table'`, `path()` 추가 / 항목명을 "공장별 현황비교"로 교체(`mod-cmp`/`part-cmp`)

- `admin`: 1컬럼 2항목 → **6컬럼 약 60항목** (시스템/기초정보/설비기초정보/공법기본관리/이벤트/도장DB)
- `mtrm`: Tech PR을 별도 컬럼(`view:'tech-pr'`)으로 분리, `path()` 갱신
- **오타 수정**: 파이로트→파이롯트, 공법편찬조회→공법권한조회, 부차대→부자재, 편성표→편성효율, 완공장→전공장, CT 상세 현황(인원별)→(인원/풀번)

- **검증**: `cd src/frontend && python -m http.server 8777` → Playwright `NODE_PATH="$(npm root -g)" node <script>.js`
