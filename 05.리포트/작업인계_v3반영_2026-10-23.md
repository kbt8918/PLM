## 작업 중 발견·수정한 버그 6건 (재발 주의)

### jQuery 이벤트 위임 함정 3종

위임(`$(document).on('click','[data-action]')`)은 **버블링 경로상의 모든 매칭 조상**에서 발동한다.

1. **오버레이 배경 닫기가 내부 버튼까지 닫음** — 오버레이에 `data-action="lk-close"`를 걸고 내부에 "선택"/"조회" 버튼을 두면 즉시 닫힌다. → 배경 직접 클릭일 때만 닫도록 제한(`$el.hasClass('rm-modal-overlay') && e.target !== this`).
2. **tr + 내부 체크박스 중복 액션 → 토글 상쇄** — 둘 다 같은 `data-action`이면 한 클릭에 두 번 발동해 선택이 켜졌다 꺼진다. → 액션은 `tr`에만, 체크박스는 `pointer-events:none`.
3. **체크 칸 클릭이 행 상세까지 엶** — `pp-open`/`tt-open`에서 `closest('[data-action="..-check"]')` 검사로 차단.

### 그 외 3건

4. **CSS 주석 조기 종료** — 주석에 `(mp-*/bp-*)`를 쓰면 `*/`가 주석을 끝내버려 **이후 규칙 전체가 깨진다**. `.mp-head`의 flex가 죽어 제목·버튼이 겹쳤고 mp/bp/cmp 4개 화면이 영향받았다. 주석에 `*/`를 포함하지 말 것.
5. **`var` 이름 충돌** — SCR-013이 이미 `var TT`를 써서 호이스팅으로 덮어써져 tt-plan이 렌더되지 않았다. → `TTP`로 분리. **render.js에 새 모듈 별칭을 만들 때 기존 선언을 먼저 grep할 것.**
6. **`?screen=` 파라미터 제약** — 정규식이 `SCR-NNN|MTRM-MAIN|todo-main`만 허용해 신규 소문자 view로 진입 불가했다. → 신규 9개 id 추가.
