Description

No.영역요소설명
1 탭 영역 부품 공정 /
모듈 공정 탭		 공정 유형(부품/모듈)을 전환하는 탭.

노출조건: 화면 진입 시 항상 표시. 기본 활성 탭은 "부품 공정".
입력조건: 탭 클릭으로 전환.
출력조건: 선택 탭 아래 상세 표(요약 현황/공정별 상세)가 탭 유형에 맞춰 갱신.
인터랙션: 탭 전환 시 하단 콘텐츠 페이드 전환.
2 필터 영역 조건 필터
(제조군/제품/지역/공장/라인)		 공정 데이터를 조회할 조건을 선택하는 필터 셀렉트박스 5종과 조회 버튼.

노출조건: 항상 표시. 기본값은 전체(전체 라인 조회).
입력조건: 상위(제조군) 선택 시 하위(제품/지역/공장/라인) 옵션 연동 변경. 조회 버튼 클릭 시 하단 표 갱신.
예외 Case:
· 조회 결과 데이터 없음 → 표 영역에 "조회된 데이터가 없습니다." 안내 표시.
· 네트워크 오류 시 → toast: "잠시 후 다시 시도해주세요."
BE 연동: GET /api/automation/parts/summary?factory=&line=®ion=&product=&group=
3 요약 현황 요약 현황 표 라인별 자동화율/직접인원/완료연한을 한눈에 비교하는 요약 매트릭스.

노출조건: 필터 조회 결과에 따라 라인 컬럼이 동적으로 구성.
출력조건: 자동화율은 "현재%~목표%(증감폭)" 형식, 직접인원은 "현재명~목표명(감소폭)" 형식으로 표시. 개선폭이 큰 값은 강조 표시(△/▼ 표기).
BE 연동: 부품/모듈 공정배치 원천 데이터 집계 배치 결과를 조회(GET /api/automation/parts/summary).
4 상세 영역 공정별 상세 표 공정 단위(오버몰딩, 파워히트 비파괴재 등)로 현재/개선 상태와 라인별 확대(전개/계획) 현황을 표시하는 상세 매트릭스.

노출조건: 필터 조회 시 공정 목록과 라인 컬럼이 함께 갱신.
출력조건: 셀 값은 "자동/수동" 배지, "가능('연도)", "발의/검토(ROI·성과 사유) N명", "미적용(사유) N명" 등 상태별 표기 규칙을 따른다.
인터랙션: 행(공정) 클릭 시 상세 이력/특성 팝업 오픈(연계 화면, 본 샘플 범위 외).
관리자 화면 연동: 신규 공정 등록 시 표준공정 마스터 관리 목록에 반영.
BE 연동: GET /api/automation/parts/process-detail
5 CTA 영역 공정 등록 / 엑셀 / 메일링 교육 버튼 공정별 상세 표에 대한 데이터 조작·내보내기·안내 액션.

입력조건: "+ 공정 등록" 클릭 시 공정 등록 팝업 오픈, "엑셀" 클릭 시 현재 조회 결과를 xlsx로 다운로드, "메일링 교육" 클릭 시 안내 팝업 오픈.
예외 Case:
· 공정 등록 시 필수값 누락 → alert: "필수 항목을 입력해주세요."
· 엑셀 다운로드 대상 데이터 없음 → alert: "다운로드할 데이터가 없습니다."
BE 연동: POST /api/automation/parts/process, GET /api/automation/parts/export
6 유틸 영역 업무프로세스 가이드 / 공감동 님 / 로그아웃 상단 우측 유틸리티 메뉴.

노출조건: 로그인 상태에서 항상 표시. "공감동 님"은 SSO(MPASS) 로그인 사용자명으로 치환.
입력조건: 로그아웃 클릭 시 세션 종료 후 PNDES 로그인 화면으로 이동.
