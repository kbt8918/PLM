# 화면설계서 Description(상세설명) 작성 가이드

> 본 문서는 Document Chaining 17단계 산출물이 아닌 온디맨드 참고 자료입니다. NotebookLM에 등록하지 않습니다.
> 적용 대상: `02.기획문서/화면설계서.md` 및 화면설계서 성격의 모든 산출물(예: `05.리포트/화면설계서_부품공정자동화현황_샘플.html`)의 우측 Description 표.
> 확정일: 2026-08-13 (4차 정정 반영 최종본)

## 1. 표 구조 원칙

| 원칙 | 내용 |
| --- | --- |
| NO 컬럼 | **영역 번호만** 기입한다 (`1`, `2`, `3` …). 요소 번호(`1-1` 등)는 NO 컬럼에 넣지 않는다. |
| 행 단위 | **영역 1개 = 표의 행(tr) 1개.** 영역에 속한 요소가 여러 개여도 행을 나누지 않고, 하나의 셀 안에 영역명 설명 → 요소별 설명 순서로 모두 이어서 작성한다. |
| 오버플로우 처리 | 한 행의 내용이 페이지 높이를 넘으면, 넘친 지점(영역명 인트로 또는 요소 단위 청크 경계)부터 잘라 다음 페이지로 이어서 노출한다. 이어지는 행은 **같은 NO 값을 반복**하고 점선 상단 테두리(`cont-row`)로 이전 페이지에서 이어졌음을 표시한다. 항목(NO) 단위가 아니라 **영역 내부의 청크 단위** 분할이다. |
| 정렬 | Description에 노출되는 모든 문구는 **좌측 상단 정렬**(`text-align:left; vertical-align:top`)로 정렬한다. |

## 2. 셀 내용 작성 순서

각 영역(행)의 '설명' 셀은 아래 순서로 작성한다.

1. **영역명** — `영역명:` 레이블 뒤 영역 이름, 다음 줄에 `ㄴ`로 시작하는 영역 전체의 기능 설명 문장.
2. **요소** — 영역에 속한 요소가 **2개 이상**이면 `요소:` 레이블 뒤에 `영역NO-요소순번`(예: `1-1`, `1-2`) 번호와 요소명을 붙여 요소별로 구분해 작성한다. **요소가 1개뿐이면 번호 없이 요소명만** 쓴다 (`요소: 조건 필터 & 조회 버튼` — `2-1`처럼 번호를 붙이지 않음).
3. 요소별로 아래 항목을 순서대로 작성하되, 해당 사항이 없는 항목은 생략한다.
   - 노출조건
   - 입력조건
   - 출력조건
   - 인터랙션
   - 예외 Case 처리 (Case별 alert 문구 포함)
   - 관리자 화면 연동 처리
   - Back-end 연동 처리
4. **영역명, 요소명, 요소 NO는 볼드 처리**한다.

## 3. 작성 예시

**영역 1 (요소 2개 이상 — 볼드 처리)**

```
영역명: 탭 영역
ㄴ 부품 공정 / 모듈 공정 탭으로 공정 유형을 전환하는 영역이다. 요소 2종(부품 공정 탭, 모듈 공정 탭)으로 구성된다.

요소: 1-1 부품 공정 탭
노출조건: 화면 진입 시 항상 표시. 기본 활성 탭.
입력조건: 클릭 시 활성화. 활성화되면 하단 요약 현황·공정별 상세 표가 부품 공정 데이터로 갱신.
출력조건: 활성 시 다크 배경의 필 형태로 강조 표시.
인터랙션: 탭 전환 시 하단 콘텐츠 페이드 전환.

요소: 1-2 모듈 공정 탭
...
```

**영역 2 (요소 1개 — 번호 생략)**

```
영역명: 필터 영역
ㄴ 제품군/제품/지역/공정/라인 5종 셀렉트 필터와 조회 버튼으로 구성된 조건 필터 영역이다.

요소: 조건 필터 & 조회 버튼
노출조건: 항상 표시. 기본값은 전체(전체 라인 조회).
입력조건: 상위(제품군) 선택 시 하위(제품/지역/공정/라인) 옵션이 연동되어 변경. 조회 버튼 클릭 시 하단 표 갱신.
예외 Case: 조회 결과 데이터 없음 → alert: "조회된 데이터가 없습니다."
BE 연동: GET /api/automation/parts/summary?...
```

## 4. 페이지 분할(오버플로우) 예시

`화면설계서_부품공정자동화현황_샘플.html` 기준, 영역 3(요약 현황)의 내용이 1페이지를 넘어가 아래처럼 처리된 사례:

- 1페이지: NO=3 행에 "영역명: 요약 현황" 인트로만 노출, 하단에 "다음 화면에 계속 ▼" 표시
- 2페이지: NO=3 행이 `cont-row`로 다시 시작되며 "요소: 요약 현황 표" 이하 상세 내용이 이어짐

## 5. 변경 이력

| 차수 | 정정 내용 |
| --- | --- |
| 1차 | 영역 단위 1행 → 요소별 넘버링 도입, 상세 항목 7종 정의(노출조건 제외) |
| 2차 | 노출조건을 상세 항목 리스트 맨 앞에 재포함 |
| 3차 | "영역명"/"요소" 레이블 구조화, 좌측 상단 정렬 명시 (이때는 요소마다 별도 행으로 분리) |
| 4차 (최종) | NO 컬럼은 영역번호만, 단일 요소는 번호 생략, **요소별 행을 다시 영역당 1행으로 통합**, 오버플로우 시 청크 단위 이어쓰기, 영역명/요소명/요소NO 볼드 처리 |
