# 화면설계서(와이어프레임) 템플릿

이 문서는 첨부된 PPT/PDF 화면설계서 템플릿(1슬라이드 = 1화면)의 구조를 마크다운으로 정리한 것입니다.
Claude Code가 화면설계서를 자동 생성/작성할 때 이 구조를 그대로 따라 각 화면(SCR-XXX)마다 하나의 섹션을 채우면 됩니다.

## 1. 슬라이드(화면) 레이아웃 구조

> ⚠️ **레이아웃 구조와 사이즈는 화면마다 절대 변경하지 않습니다.**
> 슬라이드 크기(16:9, 960×540pt / 13.333×7.5in)와 헤더·캔버스·설명·푸터 4개 영역의 위치·비율은 모든 SCR-XXX 화면에 동일하게 고정 적용합니다. 화면마다 달라지는 것은 오직 **내용(텍스트, 와이어프레임 요소, 설명)** 뿐이며, 영역의 크기·위치·순서는 절대 재배치하거나 리사이즈하지 않습니다.

한 화면은 아래 4개 영역으로 구성되며, 이 구조는 모든 화면에서 동일하게 고정됩니다.

| 영역 | 위치 | 내용 |
|---|---|---|
| 헤더(Header) | 상단 | 화면 ID, 화면명, URL, 상태 정보 |
| 캔버스(Canvas) | 좌측 대형 영역 | 실제 와이어프레임(화면 UI 목업)이 그려지는 공간 |
| 설명(Description) | 우측 세로 영역 | 화면 요소에 대한 번호별 상세 설명 표 |
| 푸터(Footer) | 하단 | 다음 화면으로 이어지는지 여부 표시 |

### 1-1. 헤더(Header) 영역

- **Screen ID**: 화면 고유 번호. 뱃지(박스) 형태로 좌상단에 표시. 예: `SCR-001`
- **Screen**: 화면명(한글 명칭). 예: `부품 공정 자동화 현황`
- **URL**: 해당 화면의 라우트/경로. 예: `/portal/automation/parts`
- **Status**: 화면 설계 진행 상태. 예: `와이어프레임 (샘플, 보정 예정)`
  - 상태값 예시: `와이어프레임`, `시안 확정`, `개발 완료`, `검수 중` 등 프로젝트에서 정의한 값 사용

### 1-2. 캔버스(Canvas) 영역

- 화면 좌측 대부분을 차지하는 빈 사각형 영역
- 실제 UI 와이어프레임(버튼, 표, 차트, 입력폼 등 목업 요소)을 배치하는 공간
- 템플릿 상태에서는 비어 있음(내용 없음)

### 1-3. 설명(Description) 영역

우측에 위치한 표. 캔버스에 배치된 UI 요소를 번호로 매칭하여 설명.

| NO | 상세설명 |
|---|---|
| 1 | (캔버스 내 ① 요소에 대한 설명) |
| 2 | (캔버스 내 ② 요소에 대한 설명) |
| 3 | (캔버스 내 ③ 요소에 대한 설명) |

- 캔버스에 요소를 추가할 때는 해당 요소에 번호(①, ②, ③ …)를 표시하고, 우측 표의 NO와 매칭되는 상세설명을 작성
- 요소 개수에 따라 행(row)은 자유롭게 추가/삭제 가능

### 1-4. 푸터(Footer) 영역

- 하단 우측에 `다음화면에계속 ▼` 문구
- 한 화면 설명이 여러 슬라이드/섹션에 걸쳐 이어질 경우 표시
- 마지막 화면(또는 이어지는 내용이 없는 경우)에는 생략 가능

### 1-5. 고정 사이즈/비율 (변경 금지)

| 영역 | 위치(비율 기준) | 비고 |
|---|---|---|
| 전체 슬라이드 | 960 × 540 pt (13.333 × 7.5 in, 16:9) | PowerPoint 기본 와이드스크린 규격 고정 |
| 헤더 | 상단 약 0 ~ 8% 높이, 전체 폭 | Screen ID / Screen / URL / Status 4열 고정 배치 |
| 캔버스 | 좌측 약 0 ~ 76% 폭, 헤더 하단 ~ 하단 전 | 와이어프레임 콘텐츠 영역, 좌측 정렬 고정 |
| 설명(Description) | 우측 약 76 ~ 100% 폭, 헤더 하단 ~ 하단 전 | NO / 상세설명 2열 표 고정 |
| 푸터 | 하단(설명 영역 폭과 동일) | "다음화면에계속 ▼" 문구, 우측 정렬 고정 |

> 위 비율/좌표 값은 화면 수·내용과 무관하게 모든 SCR-XXX 화면에서 동일하게 유지되어야 합니다.

## 2. 재사용 가능한 마크다운 템플릿

새 화면을 추가할 때 아래 블록을 복사해서 사용하세요.

```markdown
## SCR-XXX. {화면명}

- **Screen ID**: SCR-XXX
- **Screen**: {화면명}
- **URL**: {/경로/예시}
- **Status**: {와이어프레임 / 시안 확정 / 개발 완료 등}

### 와이어프레임 캔버스 설명

(화면 내 배치될 UI 요소를 ①, ②, ③ 순서로 나열하거나, 레이아웃을 텍스트/ASCII로 스케치)

### Description

| NO | 상세설명 |
|---|---|
| 1 | |
| 2 | |
| 3 | |

> 다음 화면에 계속 (해당 시)
```

## 3. 예시 (첨부 템플릿 원본 데이터)

## SCR-001. 부품 공정 자동화 현황

- **Screen ID**: SCR-001
- **Screen**: 부품 공정 자동화 현황
- **URL**: /portal/automation/parts
- **Status**: 와이어프레임 (샘플, 보정 예정)

### 와이어프레임 캔버스 설명

(현재 템플릿 샘플 단계로 캔버스 내용 없음 — 실제 화면 설계 시 이 영역에 UI 요소를 채워 넣을 것)

### Description

| NO | 상세설명 |
|---|---|
| 1 | |
| 2 | |
| 3 | |

> 다음 화면에 계속 ▼

## 4. Claude Code 작업 시 참고 사항

- **레이아웃 구조와 사이즈는 절대 변경하지 않습니다.** 슬라이드 규격(16:9, 960×540pt)과 헤더·캔버스·설명·푸터 4영역의 위치·비율은 "1-5. 고정 사이즈/비율" 표를 그대로 따르며, 화면마다 재조정하지 않습니다.
- 화면 여러 개를 한 문서에 이어서 작성할 경우, 위 "2. 재사용 가능한 마크다운 템플릿" 블록을 화면 수만큼 반복하여 `##` 레벨 섹션으로 이어붙이면 됩니다. (레이아웃은 고정, 내용만 교체)
- Screen ID는 `SCR-001`, `SCR-002` … 순번으로 증가시킵니다.
- Description 표의 NO는 캔버스에 표시된 UI 요소 번호(①②③…)와 1:1로 매칭되어야 합니다.
- Status 값은 프로젝트 진행 단계에 맞춰 통일된 용어를 사용하는 것을 권장합니다.
